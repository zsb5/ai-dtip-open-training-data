## Intended AI-DTIP mapping

| Source fields | Intended target use |
|---|---|
| `G1`, `G2`, `G3` | staged and final grade validation |
| `studytime` | study-effort test attribute |
| `absences` | attendance/absence test attribute |
| `failures` | prior-failure risk test attribute |

These records are test and benchmarking inputs. They are not real AI-DTIP
employees or learners.
